# Changelog

All notable changes to this project are listed here. Versions follow [Semantic Versioning](https://semver.org).

## [1.0.0] - 2026-10-15

First public release of **Shell to Home**.

### Added
- Photo uploads with drag and drop, thumbnails, and checks for small, dark, blurry or unclear images (plus a HEIC tip).
- Room types: living room, kitchen, bedroom, bathroom, full house exterior.
- Five preset styles: modern minimalist, Scandinavian, luxury contemporary, Indian modern, industrial loft.
- Up to 5 reference images per project, with roles (overall style, flooring, kitchen, colour palette, furniture), a "references used" list for each render, and layout/scale conflict warnings.
- Free in-browser preview renderer: room box fitting, procedural materials, the photo's own lighting, door and window detection, downlights and cove lighting, 3D furniture.
- Optional AI engines: OpenAI and Google Gemini image editing, and a Claude reference check.
- Before/after slider, side-by-side and after-only views; auto-update when the style or references change.
- One-element-at-a-time editing for flooring, walls, ceiling, lighting, fixtures, cabinets and furniture.
- Save, download, and before/after image download; projects stored in IndexedDB.
- 3D house with walkthrough preview, explore mode, MP4 export (WebCodecs or ffmpeg) with progress, and GLB export.
- Static build and GitHub Pages deployment, SEO metadata, docs and tests.
